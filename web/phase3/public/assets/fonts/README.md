# Fonts Assets

Thư mục này dùng để lưu trữ font chữ cục bộ (`.woff2` / `.ttf`) cho chế độ offline hoặc self-host nếu không tải qua Google Fonts (`Be Vietnam Pro`, `JetBrains Mono`).
Khi bổ sung font cục bộ, khai báo `@font-face` tại `src/styles/base/tokens.css` và đồng bộ tên font tại `src/config/typography.ts`.
